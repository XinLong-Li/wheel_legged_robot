## 硬件参考

| 部件 | 推荐型号 | 说明 |
|------|----------|------|
| 主控 | Raspberry Pi 4B/5 | ROS2 上位机 |
| 底层控制器 | ESP32 (ESP32-S3) | FOC 电机实时控制 |
| FOC 驱动 | SimpleFOC + AS5600 编码器 | 开源 FOC 方案 |
| IMU | MPU6050 / ICM-20948 | 六轴/九轴姿态传感器 |
| 电机 | BLDC 无刷电机 (如 2204/2208) | 小型无刷 |
| 舵机 | (待定) | 关节驱动可选方案 |
