## 自由度 (DOF) 设计

轮腿机器人本体共 **8 个自由度**：

| 部件 | 关节/电机 | 数量 |
|------|-----------|------|
| 左腿 | 髋关节 (pitch) | 1 |
| 左腿 | 膝关节 (pitch) | 1 |
| 左腿 | 踝关节 (pitch) | 1 |
| 右腿 | 髋关节 (pitch) | 1 |
| 右腿 | 膝关节 (pitch) | 1 |
| 右腿 | 踝关节 (pitch) | 1 |
| 左脚 | 轮子 | 1 |
| 右脚 | 轮子 | 1 |
| **合计** | | **8** |

## 控制架构

采用分层控制方案：

```
┌─────────────────────────────────┐
│      高层：任务规划               │
│   (步态选择 / 路径规划 / 行为树)   │
└───────────┬─────────────────────┘
            │ 目标姿态 / 速度
┌───────────┴─────────────────────┐
│      中层：全身控制 (WBC)        │
│   平衡 + 运动学 + 力分配         │
└───────────┬─────────────────────┘
            │ 关节目标 (角度 / 力矩 / 速度)
┌───────────┴─────────────────────┐
│      底层：FOC 电流环控制        │
│   ESP32 + SimpleFOC (10kHz)     │
└─────────────────────────────────┘
```

## ROS2 节点通信

```
                    ┌─────────────┐
                    │  /imu_data  │ (sensor_msgs/Imu)
                    └──────┬──────┘
                           │
  ┌─────────────┐    ┌─────┴──────┐    ┌──────────────┐
  │ wlr_teleop  │───>│wlr_controller│<───│wlr_state_est │
  │ /cmd_vel    │    │             │    │ /joint_states│
  └─────────────┘    └─────┬───────┘    └──────────────┘
                           │ /joint_commands
                    ┌──────┴──────┐
                    │ wlr_driver  │
                    │ (serial)    │
                    └─────────────┘
```

### 自定义消息 (wlr_msgs)

- `JointCommand.msg` — 多关节控制指令
- `JointState.msg` — 多关节状态反馈
- `WheelCommand.msg` — 轮速指令
- `RobotStatus.msg` — 机器人整体状态

## 通信协议 (ESP32 ↔ RPi)

使用自定义二进制协议，UART 3Mbps：

```
帧格式:
┌──────┬──────┬────────┬─────────┬──────┐
│ 帧头  │ 长度  │ 命令ID  │ 数据段   │ 校验  │
│ 2B   │ 1B   │ 1B     │ N bytes │ 1B   │
└──────┴──────┴────────┴─────────┴──────┘
帧头: 0xAA 0x55
校验: XOR 校验和
```

上行 (ESP32 → RPi): IMU数据、关节状态、电机电流
下行 (RPi → ESP32): 关节目标角度、轮速指令、参数配置
